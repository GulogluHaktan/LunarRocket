The analytic evaluation code (the NumPy port of the three blending functions, the continuity and cost metrics, and the ablation scripts) and the production environment code (the Isaac Lab task definition together with the \texttt{ISAACLAB\_TERRAIN\_BLEND\_METHOD}-selectable integration of the three methods) are kept in the authors' project repository and are available from the corresponding author on reasonable request. A public release is planned to accompany final publication.
