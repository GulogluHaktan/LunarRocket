The analytic evaluation code (the NumPy port of the three blending functions, the continuity and cost metrics, and the ablation scripts) and the production environment code (the Isaac Lab task definition together with the ISAACLAB_TERRAIN_BLEND_METHOD-selectable integration of the three methods) are publicly available in the repository https://github.com/GulogluHaktan/LunarRocket. The release v1.0.0 is permanently archived on Zenodo (https://doi.org/10.5281/zenodo.23452185).
