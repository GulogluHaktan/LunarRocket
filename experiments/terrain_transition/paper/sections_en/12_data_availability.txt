The analytic evaluation code used in this study (the NumPy port of the three blending functions, the continuity/cost metrics, the ablation scripts), the production environment code (the Isaac Lab task definition and the ISAACLAB_TERRAIN_BLEND_METHOD-selectable integration of the three methods), and the raw experimental outputs (the thirty-seed continuity measurements, the four ablation sweeps, the real training TensorBoard logs) are kept in the author's project repository and are available from the author on reasonable request. Moving the code to a public repository during the review process is planned.
